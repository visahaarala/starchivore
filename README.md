# Starchivore

[https://starchivore.singingtrumpet.com](https://starchivore.singingtrumpet.com)

This is a simple foods explorer, a tool for understanding the McDougall starchivore diet. Turning on the starchivore toggle filters away foods with fiber/sugar < 0.3 and fiber/fat < 0.45.

Only foods with scientific name, raw, and fiber > 0 are included.  
Plus all the seeds (not raw in the Fineli database).

Website in vanilla html, css & javascript. Data manipulation in typescript.  
Deployed at Vercel.

Source of data is Peruspaketti 1  
(Basic package 1)
